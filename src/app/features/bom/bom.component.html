🧩 BOM — Estrutura dos Kits

O BOM (Bill of Materials) é a estrutura de cada kit: os materiais/componentes consumidos e os processos usados na montagem (com horas). O custo é calculado automaticamente (materiais + processos) e o estoque é controlado pelos componentes. Para criar um novo kit, cadastre um produto do tipo Kit no menu Produtos.
